# LED Sign Project - 96x16 RGB Matrix

Pi Zero 2W powered LED sign with 6 high-performance visual effects.

## Features
- 🌈 6 optimized effects (rainbow, fire, matrix, stars, pulse, scanner)
- ⚡ 30 FPS smooth rendering
- 📱 React Native mobile control app
- 🔌 USB auto-detection for LED panels
- 🧪 Mock mode for testing without hardware

## Quick Start
```bash
pip3 install -r requirements.txt
python3 app.py
```

## Effects
| Effect | Description |
|--------|-------------|
| 🌈 rainbow | Smooth rainbow waves |
| 🔥 fire | Realistic fire simulation |
| ⭐ stars | Parallax starfield |
| 💚 matrix | Digital rain |
| 💙 pulse | Breathing glow |
| 📡 scanner | Radar sweep |

## Hardware
- Raspberry Pi Zero 2W
- 96x16 LED matrix panel (USB/Serial)
- 5V power supply
